# DecodeLabs Virtual Internship – Cybersecurity

This repository contains the projects completed as part of the **DecodeLabs Virtual Internship Program in Cybersecurity**.

The tasks focus on applying Python programming concepts to practical cybersecurity problems, covering password security and introductory cryptography.

## Completed Tasks

### Task 1: Password Strength Checker

A Python-based program that evaluates password strength using predefined validation conditions.

**Key Features**
- Checks password length.
- Identifies uppercase letters.
- Detects numerical digits.
- Checks for special symbols.
- Classifies passwords as Weak, Medium, or Strong.

**Concepts Used:** Python, string handling, conditional statements, character checking, and basic password security.

### Task 2: Basic Encryption and Decryption

A Python-based implementation of the Caesar Cipher, a basic substitution encryption technique.

**Key Features**
- Accepts text and a numerical shift key.
- Encrypts text using the Caesar Cipher.
- Decrypts the encrypted message using the same key.
- Displays the original, encrypted, and decrypted text.

**Concepts Used:** Python, ASCII character conversion, loops, shift keys, and modular arithmetic.
